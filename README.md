# 🧰 研究工具与基础设施

这里收录支持科研规划、实验、论文写作、评测与协作的工具。此仓库是项目目录；工具代码、发布记录和问题跟踪保留在各自的独立仓库。

## 项目列表

- [keresearch](https://github.com/Infinite-Monkey-Lab/keresearch) — 面向 ZCode、Claude Code 与 Codex 的科研 Agent Skills。

## 收录字段规范

每个项目条目应链接到独立主页，并说明用途、当前状态、维护者、许可证、安装或快速开始方式、支持的平台和问题反馈入口。未知信息标注“待确认”，不要推测许可证或维护状态。

新增或更新条目时，可复制[项目条目模板](https://github.com/Infinite-Monkey-Lab/.github/blob/main/PROJECT_ENTRY_TEMPLATE.md)。

## 提交项目

[在组织 Discussions 提交研究工具](https://github.com/orgs/Infinite-Monkey-Lab/discussions/new/choose)。请附项目主页、解决的问题、安装或使用方式和维护状态。
